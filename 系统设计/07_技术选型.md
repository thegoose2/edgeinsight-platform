## 3. 选型说明与影响分析

### 3.1 Spring Data JPA 对 Repository 接口的影响

`TelemetryRepository` 接口使用 Spring Data JPA 风格，分页参数采用 `Pageable` 和 `Page<T>`，时间类型使用 `Instant`：

```java
// Spring Data JPA 分页风格（采用）
Page<TelemetryRecord> findHistory(long deviceId, String pointCode,
                                  Instant from, Instant to,
                                  Pageable pageable);
```

与团队其他产品保持一致，降低跨项目的上下文切换成本。扩展点③切换时序数据库时，新实现类同样沿用此接口签名，上层调用代码零改动。

### 3.2 EasyExcel 覆盖批量导入

设备批量导入（`POST /api/v1/device/import`）直接使用 EasyExcel 实现：
- 读取 Excel 文件：`EasyExcel.read()` + 自定义 `ReadListener`
- 部分成功策略：在 `ReadListener.invoke()` 中逐行校验，收集错误行，不中断整体读取
- 模板下载：`EasyExcel.write()` 生成标准导入模板供交付工程师使用

### 3.3 WebSocket 实现

Spring Boot 2.7.x 内置 `spring-websocket`，无需额外依赖，直接使用即可覆盖在离线状态推送和遥测实时推送需求（V1.1 迭代实现）。

### 3.4 待补充选型（扩展点启用时）

| 扩展点 | 需要补充的依赖 | 说明 |
|------|------|------|
| 扩展点① TCP Adapter | Netty 4.x | 实现 TcpAdapterServer、TcpFrameDecoder 等组件 |
| 扩展点③ 时序数据库 | TDengine JDBC 驱动 / TimescaleDB 驱动 | 替换 MySQL TelemetryRepository 实现时按需引入 |

## 4. 版本兼容性说明

| 约束 | 说明 |
|------|------|
| Java 11 + Spring Boot 2.7.x | Spring Boot 3.x 需要 Java 17，当前技术栈锁定 2.7.x |
| Moquette 0.17 | 当前可用的纯 Java 内嵌版本，注意 `IAuthenticator` 接口签名与旧版有差异 |
| Spring Data JPA + MySQL 8.0+ | 需配置 `spring.jpa.database-platform=org.hibernate.dialect.MySQL8Dialect` |
| EasyExcel 3.3.x + Java 11 | 需排除 `poi` 旧版依赖冲突，确保使用 poi 5.x |
