## 二、已完成设计项

### 2.1 基础架构


| 设计项         | 说明                                                                       |
| ----------- | ------------------------------------------------------------------------ |
| 整体分层架构      | 五层架构：接入适配 → 解析转换 → 数据访问 → 业务逻辑 → 开放接口                                    |
| Maven 多模块结构 | 7个模块：common / parser-spi / adapter-spi / core / adapter-mqtt / api / app |
| 内部解耦机制      | Spring ApplicationEvent 异步事件总线，4类核心事件                                    |
| 公共基类体系      | BaseEntity / AuditableEntity / BaseService / Result / 统一异常               |
| 技术选型        | Spring Boot 2.7.x + JPA + Moquette + MySQL + EasyExcel 等全栈确认             |


### 2.2 数据库设计（14张表）


| 分类      | 表名                                                                           |
| ------- | ---------------------------------------------------------------------------- |
| 协议与设备配置 | `protocol_profile`、`device_type`、`device_type_point`                         |
| 设备实例    | `device`、`device_status`、`device_connectivity_log`                           |
| 遥测数据    | `telemetry_record`（按月分区）、`telemetry_latest`                                  |
| 系统配置    | `system_config`                                                              |
| 用户权限    | `sys_user`、`sys_role`、`sys_permission`、`sys_user_role`、`sys_role_permission` |


### 2.3 设备管理模块


| 设计项               | 说明                                                   |
| ----------------- | ---------------------------------------------------- |
| 设备类型与测点模板         | 策略 A（模板即契约），device_type_point 是权威来源                  |
| 设备注册与管理           | 设备档案、lifecycle_status（ACTIVE / INACTIVE）、批量 Excel 导入 |
| 协议档案管理            | ProtocolProfile 配置，研发预置，交付时选用                        |
| GatewayProfile 机制 | 按网关型号共享，Device 通过 device_type_id 获取协议配置              |


### 2.4 设备接入模块


| 设计项                | 说明                                                                    |
| ------------------ | --------------------------------------------------------------------- |
| MQTT 认证            | connect_id 白名单，实现 Moquette IAuthenticator                             |
| Topic 规范           | 4个标准 Topic：telemetry / status / command / command/reply               |
| 第三方网关适配            | ProtocolProfile.topic_patterns + msg_type_mapping 配置适配                |
| ResolvedContext 缓存 | 连接建立时加载，含 device_id / parser_id / validPointCodes / lifecycleStatus 等 |


### 2.5 解析层设计


| 设计项                | 说明                                                                            |
| ------------------ | ----------------------------------------------------------------------------- |
| ParsedMessage 类型层次 | 4个子类：TelemetryMessage / HeartbeatMessage / DeviceAlarmMessage / StatusMessage |
| ParserRouter       | connect_id → ProtocolProfile → parser_id → 解析器，无协议 if/else                    |
| 解析器分类策略            | MQTT 内置 DefaultJsonParser；TCP 解析器 100% 来自独立解析器库                               |


### 2.6 数据写入模块


| 设计项                    | 说明                                                              |
| ---------------------- | --------------------------------------------------------------- |
| TelemetryIngestService | 生命周期校验 → 测点白名单校验 → 双表写入（record + latest） → 发布事件                 |
| telemetry_latest 乱序保护  | upsert 时判断时间戳新旧，补传历史数据不覆盖最新值                                    |
| TelemetryRepository 接口 | save / saveBatch / findLatest / findHistory / streamRange（扩展点③） |


### 2.7 在离线管理模块


| 设计项      | 说明                                                                      |
| -------- | ----------------------------------------------------------------------- |
| 三层离线判定   | MQTT 断开+宽限期 / 网关主动上报 / TCP 断开+宽限期                                       |
| 宽限期分协议配置 | mqtt.grace_period_secs（30s）/ tcp.grace_period_secs（60s）                 |
| 在线率统计    | device_connectivity_log 双字段（online_duration_s + offline_duration_s）直接聚合 |
| 服务重启恢复   | 启动时一次性补偿扫描，恢复未完成的计时任务                                                   |


### 2.8 用户权限模块


| 设计项         | 说明                                                |
| ----------- | ------------------------------------------------- |
| RBAC 模型     | 用户 → 角色 → 权限，支持自定义角色                              |
| 双层权限粒度      | 菜单权限（MENU）控制页面入口 + 操作权限码（OPERATION）控制高风险操作        |
| 4个内置角色      | 系统管理员 / 运维人员 / 生产管理者 / 一线操作员，is_system=1 不可删除     |
| JWT 单 Token | 有效期 8 小时（system_config 可配），Token 携带 roles + perms |
| 公开接口机制      | 路径白名单（application.yml）+ @Anonymous 注解双层支持         |


### 2.9 API 接口


| 模块     | 接口数量                 |
| ------ | -------------------- |
| 认证接口   | 3个（登录 / 登出 / 获取用户信息） |
| 用户管理   | 8个                   |
| 角色管理   | 6个                   |
| 权限查询   | 1个                   |
| 协议档案管理 | 4个                   |
| 设备类型管理 | 5个                   |
| 测点模板管理 | 4个                   |
| 设备管理   | 6个（含批量导入）            |
| 遥测数据查询 | 2个                   |
| 在离线查询  | 2个                   |
| 系统配置   | 2个                   |
| **合计** | **43个**              |
